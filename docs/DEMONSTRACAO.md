# Demonstração do AgendaUni

Roteiro para uma apresentação de aproximadamente dois minutos, usando somente dados fictícios. Execute o aplicativo em uma instalação limpa e teste o fluxo no aparelho antes de gravar.

| Etapa | Ação | O que demonstra |
| --- | --- | --- |
| 1 | Cadastre a disciplina **Engenharia de Software**, com limite de **8 faltas**. | Cadastro e validação. |
| 2 | Acrescente um horário semanal para um dia futuro, às **19h**. | Organização das aulas. |
| 3 | Registre uma falta com o motivo **Compromisso pessoal**. | Controle por disciplina. |
| 4 | Cadastre **Entrega do projeto**, com data dez dias à frente. | Eventos acadêmicos e lembretes futuros. |
| 5 | Abra o calendário, navegue até a data e alterne os filtros. | Visão integrada dos registros. |
| 6 | Troque o tema e reabra o aplicativo com a internet desligada. | Preferência de tema e persistência offline. |

## Texto de abertura sugerido

“O AgendaUni é um aplicativo offline para organizar disciplinas, faltas, horários e avaliações. Eu o desenvolvi em C# com .NET MAUI, arquitetura MVVM e SQLite. O projeto foi concluído e é mantido como demonstração técnica.”

## Antes de compartilhar

- Use datas futuras e nomes fictícios; esconda informações pessoais do aparelho.
- Confira se cadastro, edição, exclusão e filtros funcionam na instalação usada para gravar.
- Para mostrar lembretes, autorize notificações e verifique os agendamentos no aparelho; não prometa entrega com base apenas nos testes unitários.
- Se gravar o vídeo ou gerar um APK, publique somente o artefato que você efetivamente testou e adicione o link ao README.
